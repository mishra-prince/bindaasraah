# Publishing status

Source: https://github.com/mishra-prince/bindaasraah

Public educational beta: https://bindaasraah-beta.onrender.com/

GitHub Actions runs Python and JavaScript tests on pushes and pull requests to main. Render is connected to this repository only and is configured to deploy after CI checks pass.

Secrets belong in Render environment settings. No API keys are included in source. Routing currently uses a best-effort public demo provider. This beta does not certify routes safe, provide live crowd or gender counts, or verify current lighting and service readiness.
